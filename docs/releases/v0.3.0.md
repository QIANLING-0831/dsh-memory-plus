# DSH Memory Pro v0.3.0

原 DSH Memory Plus 更名为 **DSH Memory Pro**。仓库地址、`dsh-memory-bundle` 包名、数据库路径和已有快捷键 ID 保持兼容。

这版把“新会话接着旧讨论聊”打进了可直接安装的 bundle：

- `memory_search_workspace`：搜索同工作区的活会话和磁盘历史，返回标题、时间、片段及来源引用。
- `memory_read`：按来源读取原始消息和前后上下文，核对后续纠正后再继续讨论。每次重新检查工作区归属，输出有界。
- 包含五项记忆/技能快捷键；可在快捷键面板搜索 `memory pro`，旧 `memory plus` 别名仍可用。`/memory-search` 与它的快捷键仍只搜当前会话。

## 安装或升级

```sh
dsh plugin --profile web add https://github.com/QIANLING-0831/dsh-memory-plus/releases/download/v0.3.0/dsh-memory-bundle-0.3.0.tgz
```

把 `web` 改成你实际使用的 profile。升级时重新添加这个版本 URL，重启 DSH 并刷新页面；不要删除已有记忆数据库。无需 clone 或逐个安装七个功能包。资产同时提供 `SHA256SUMS`。

需要 Node.js 24、pnpm 和兼容宿主；DSH 声明范围仍为 `>=0.1.5-rc.3 <0.3.0`。**插件 v0.3.0 与 DSH 宿主版本号独立。**

安装后可在同工作区的新会话里说：“继续上次讨论的方案，确认最终决定，附上原文来源。”模型会获得搜索与回读工具；是否主动调用仍取决于模型。

## 验证与范围

- 141 项自动测试、8 个包检查通过；打包测试包含两个跨会话实现模块及旧快捷键兼容。
- 实际 `.tgz` 通过官方 CLI 单包安装；DSH 0.2.0-rc.2 / Linux 完整 Web profile 的首次启动、冷重启、跨会话检索、原文回读、引用、工作区隔离及核心记忆持久化通过。
- 在线 `gpt-6.1-sol` 三类任务各三次，9/9 主动搜索、回读纠正并引用后续决定；使用真实 DSH 工具/存储的 MCP 测试桥，未测完整 DSH AgentLoop 在线对话，也不是 Claude 的结果。
- 默认 char-overlap 仍用于评估；真实语义召回可配置已有 transformers 嵌入。原生 Windows/macOS 桌面壳、大历史库性能、引用点击跳转未在本版补齐。
